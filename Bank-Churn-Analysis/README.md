## 📌 Overview

This project presents an interactive **Bank Customer Churn Analysis Dashboard** built using **Power BI**.  
It helps identify customer churn patterns based on demographics, financial behavior, and product usage.

The dashboard enables stakeholders to understand **why customers leave** and supports data-driven decision-making to improve retention.

---

## 🎯 Objectives
- Analyze customer churn rate  
- Identify key factors influencing churn  
- Compare active vs inactive customers  
- Provide insights by age, geography, credit score, and balance

## 📈 Insights from Dashboard

### 🌍 Geography
- Germany shows the highest churn rate (**32.4%**)  
- Spain and France have relatively lower churn (~16%)  

### 👥 Customer Demographics
- Age group **51–60** has the highest churn (~56%)  
- Younger customers (<30) show significantly lower churn  

### 💳 Credit Score Impact
- Customers with very low credit scores (**≤400**) show extremely high churn (**100%**)  
- Moderate scores have relatively stable churn (~20%)  

### 💰 Balance Analysis
- Customers with low balances (**1k–10k**) have the highest churn  
- High-balance customers (**>200k**) are more stable  

### 🧾 Product Analysis
- Product usage is fairly balanced between active and inactive users  
- Some products show slightly higher churn patterns
